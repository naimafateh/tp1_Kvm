# tp1_Kvm
## Fichiers non versionnés (trop volumineux pour GitHub)

Ces fichiers existent en local dans la structure du TP mais ne sont pas poussés (limite de 100 Mo par fichier) :

- `iso/` : ISO Ubuntu Server 24.04 (somme de contrôle dans `iso/SHA256SUMS`)
- `images/` : `ubuntu-vm01.qcow2` (VM source), `ubuntu-app01.qcow2`, `ubuntu-app02.qcow2`
- `templates/` : `ubuntu-template-v1.qcow2` (somme de contrôle dans `templates/template.sha256`)
